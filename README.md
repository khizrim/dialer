# Ozero Phone · прототип

Кликабельный прототип Android-звонилки Ozero Phone на Kotlin + Jetpack Compose. Данные выдуманные, реальной телефонии пока нет: задача этапа в том, чтобы проверить идею и интерфейс.

## Что есть

Направление «Люди + клавиатура-поиск»: вкладок нет, журнал звонков живёт внутри человека.

- **Главная.** Стопка из нескольких имён (Inter, как в Ozero Mail), ближайший человек внизу, у большого пальца. Тап по имени сразу выполняет способ связи по умолчанию. Долгое нажатие открывает меню: «Открыть карточку», «Другой способ», «Убрать с главной». После «Убрать» можно «Вернуть» или «Очистить главную».
- **Клавиатура = поиск.** Набор фильтрует людей по T9 (русская раскладка, «Аня» = 259) и по номеру, номер маскируется по региону, долгое нажатие на 0 даёт «+».
- **Человек.** Редкая хронология, главная кнопка со способом по умолчанию, «Другой способ», «Изменить по умолчанию», избранное.
- **Все контакты.** Алфавит с указателем; тап по имени открывает человека, значок справа связывает сразу.
- **Звонки.** Демо через значок вверху главной: звонит контакт, неизвестный номер с АОН, похоже на спам. Ответить, отклонить, SMS, напомнить, заблокировать; во время звонка микрофон, динамик, клавиши.
- **Движение** по `MOTION.md`: 100 / 150 / 200 / 300 мс, только сдвиг и прозрачность; при отключённых анимациях остаётся только прозрачность.
- Палитра «Озеро», светлая и тёмная тема по системе, иконки Ozero v2.

## Как запустить

- Скачать готовый APK: вкладка **Actions** → последний запуск **Build APK** → артефакт `dialer-debug-apk`.
- Или открыть проект в Android Studio и запустить на телефоне/эмуляторе (Android 8.0+).

Собрать вручную: `./gradlew assembleDebug`.

### Постоянный ключ подписи

Чтобы новые APK ставились поверх старых и не стирали настройки, CI подписывает их одним ключом из секретов репозитория. Один раз создать ключ и добавить секреты (Settings → Secrets and variables → Actions):

```sh
keytool -genkeypair -keystore ozero.keystore -alias ozero -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Ozero Phone"
base64 -w0 ozero.keystore   # на macOS: base64 -i ozero.keystore
```

- `OZERO_KEYSTORE_BASE64`: вывод base64;
- `OZERO_KEYSTORE_PASSWORD`: пароль, заданный в keytool;
- `OZERO_KEY_ALIAS`: `ozero`.

Сам файл ключа в репозиторий не кладётся. Без секретов сборка подписывается временным debug-ключом, как раньше. Для основного телефона лучше брать артефакт `ozero-phone-release-apk`: в нём нет режима отладки.
