# Ozero Phone · прототип

Кликабельный прототип Android-звонилки Ozero Phone на Kotlin + Jetpack Compose. Данные выдуманные, реальной телефонии пока нет: задача этапа в том, чтобы проверить идею и интерфейс.

## Что есть

- **Контакты.** Поиск по имени и номеру, избранное, список по алфавиту. Кнопка справа у контакта сразу выполняет его способ связи по умолчанию (например, видео в WhatsApp). Долгое нажатие на избранного открывает карточку.
- **Карточка контакта.** Большая кнопка основного действия, выбор способа связи по умолчанию (звонок, SMS, WhatsApp, Telegram, Signal, Viber или «спрашивать каждый раз»), все способы связи по приложениям, заготовка настроек уведомлений.
- **Входящий звонок.** Три сценария через иконку в шапке контактов: звонит контакт, неизвестный номер с определением АОН, подозрение на спам. Можно ответить, отклонить, отправить сообщение, напомнить или заблокировать.
- **Недавние** и **Клавиатура** для полноты картины.

## Как запустить

- Скачать готовый APK: вкладка **Actions** → последний запуск **Build APK** → артефакт `dialer-debug-apk`.
- Или открыть проект в Android Studio и запустить на телефоне/эмуляторе (Android 8.0+).

Собрать вручную: `./gradlew assembleDebug`.
